# react-java-example

I forked this example React project so I could experiment with it and figure out how to integrate React.js and Java together.
This readme contains my notes about how to run it
HELP.md contains additional information from the original creator who I forked this from

## Built with
Java, JavaScript, React.js

## Features
- This does the same thing as the original repository

## Running it
- git clone https://github.com/bbachi/react-java-example.git
- Run React on port 3000
  - cd /src/main/ui
  - npm install
  - npm start
- Run Java Code on 8080
  - mvn clean install
  - java -jar target/users-0.0.2-SNAPSHOT.jar
